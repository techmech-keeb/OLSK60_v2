# Cherry MX スイッチ 寸法リファレンス

単位はすべて mm。元図（Cherry MX データシートの DIMENSIONS / MOUNTING OPTIONS）から読み取った値と、
一般的な MX 互換寸法として補った値を分けて記載する。

## 1. 高さ方向（積み上げ）

| 部位 | 寸法 | 備考 |
|---|---|---|
| ステム突出（ハウジング上面〜ステム頂点） | 3.6 | 未押下時 |
| ハウジング全高 | 11.6 | トップ上面〜ボトム下端 |
| └ うち下部ハウジング（フランジ下面より下） | 5.0 | 11.6 の内訳 |
| ピン突出 | 3.3 | ボトム下端より下 |
| **全高** | **18.5** | 3.6 + 11.6 + 3.3 |

## 2. 外形（XY）

| 項目 | 寸法 |
|---|---|
| トップハウジング フランジ外形 | 15.6 × 15.6 |
| 下部ハウジング（プレート穴に入る部分） | 14.0 × 14.0 |
| プレート開口（推奨） | 14.0 × 14.0 |
| キースイッチピッチ | 19.05 |

## 3. マウント条件

| 項目 | 寸法 | 備考 |
|---|---|---|
| プレート厚 | 1.5 | 0.06 ±0.006 in |
| プレート下面までのハウジング長 | 4.8 | 0.197 +0.012 in |
| プレート上面〜ピン先端 | 約 8.1 | 4.8 + 3.3。元図の「< 8」相当 |
| プレート上面〜ステム頂点 | 約 10.2 | 6.6 + 3.6 |

プレートマウントでは 15.6 のフランジがプレート上面に載り、下部ハウジング側面のラッチが
厚さ 1.5 のプレートに噛む。PCB マウント（5 ピン）はこれに位置決めボスとピンが加わる。

## 4. PCB フットプリント

中央ボス中心を原点 (0, 0) とする。X は右、Y は上（＝上面から見た座標）。

| 穴 | 座標 | 径 |
|---|---|---|
| 中央ボス | (0, 0) | φ4.0 |
| 位置決めボス L | (-5.08, 0) | φ1.7 |
| 位置決めボス R | (+5.08, 0) | φ1.7 |
| 端子 1 | (-3.81, +2.54) | φ1.5 |
| 端子 2 | (+2.54, +5.08) | φ1.5 |

3 ピン（プレートマウント）版では位置決めボス 2 つが省かれる。

## 5. ステム（参考値・元図に記載なし）

| 項目 | 寸法 |
|---|---|
| 十字アーム全長 | 約 4.1 |
| 十字スロット幅 | 約 1.35 |
| ステム外形 | 約 5.5 × 5.5 |
| トラベル（フルストローク） | 4.0 |
| アクチュエーションポイント | 2.0（MX Brown / Blue 等） |

## 6. 注記

- 元図で寸法が明示されているのは §1〜§3 と §4 の座標のみ。
- §5 および「下部ハウジング 14.0」「トップ上面 11.6 角」は一般的な MX 互換寸法として補った値であり、
  厳密な設計に使う場合はメーカー図または実測で確認すること。
- インチ値は元図の併記（0.14 / 0.46 / 0.20 / 0.13 / 0.61 in など）に対応する。
