## どのファイルを書き込むか

**ファームウェアの機能はどちらも同じです。**配布ファイルが 2 つあるのは、
**出荷時のキーマップ（プリセット）**が 2 通りあるためで、スペース列ごとに
「書き込んだらそのまま使える」配置を用意しています。

| お使いのスペース列 | そのまま使えるプリセット |
|---|---|
| **5 分割**（v2.1 の出荷時） | `OLSK60_v2_firmware_v<バージョン>_Vial_5split.uf2` |
| **3 分割** | `OLSK60_v2_firmware_v<バージョン>_Vial_3split.uf2` |

**どちらを書き込んでも動作します。**キー配置は Vial でいつでも変更できるので、
あとから好みに合わせて割り当て直すこともできます。

> **プリセットが合っていないとどうなるか:** 例えば 3 分割のキーボードに 5 分割用の
> プリセットを書き込むと、Space が物理キーの無い位置に載るため、そのままでは Space が
> 打てません。**Vial で押せる位置に割り当て直せば、そのまま使えます。** 手間を省きたい
>場合は、最初からお使いのスペース列に合うプリセットを選んでください。
>
> 設定ツール側のレイアウト選択は画面表示の切り替えで、打鍵の割り当ては変わりません。

### 設定ツール

テスト版は **Vial 専用**です。**Remap / VIA には対応していません。**
キーボード定義はファームウェアに内蔵されているので、定義ファイルの読み込みは不要です。

---

## 書き込み手順

1. キーボードを PC から取り外します。
2. **ESC キーを押しながら** USB ケーブルを接続します。
3. `RPI-RP2` という名前のドライブが表示されます。
4. ダウンロードした `.uf2` ファイルを、そのドライブにコピーします。
5. コピーが終わるとキーボードが自動的に再起動します。
6. Vial で認識されることを確認してください。

> ファームウェアが起動しない状態でも、**ESC キーを押しながら挿せば**この書き込みモードに入れます。

---

## 書き込む前に

- **書き込むと、キーボードに保存された設定（キー配置・マクロ・トラックポイントの速度など）は
  初期化され、出荷時の状態に戻ります。** テスト版どうしの書き込みであれば、書き込む前に Vial の
  `Save Current Layout` で保存し、書き込み後に `Load Saved Layout` で読み込み直せます。
- ⚠️ **旧版（v2.x）で保存したレイアウトファイル（`.vil`）は読み込まないでください。**
  独自キー（速度設定・サウンド・オートレイヤーなど）の並びが変わっているため、読み込むと
  **別の機能が割り当てられます**。Vial は保存元のキーボードを確認しないので、そのまま書き込まれます。
  旧版から移行する場合は、お手数ですが Vial で組み直してください。
- 書き込み中は USB ケーブルを抜かないでください。
- 通常のご利用で問題がなければ、テスト版へ更新する必要はありません。

## 元に戻すには

正式版の `.uf2` を[最新の正式リリース](https://github.com/techmech-keeb/OLSK60_v2/releases/latest)から
ダウンロードし、上と同じ手順で書き込めば戻ります（このときも設定は初期化されます）。

## テスト版の主な変更点

- **設定ツールは Vial のみ**になりました（Remap / VIA 非対応）。
- **スペース列ごとに出荷時キーマップ（プリセット）を用意しました**（上記）。機能の違いはありません。
- **同時に押せるキーは 6 キーまで**です。
- **トラックポイントのスクロールが滑らかになりました。** 1 ノッチより細かい単位で送るため、
  ゆっくり動かしたときの追従が改善します。強く操作するほど速く進む調整も既定で有効です
  （設定レイヤーの `T` で切り替えられます）。
- **設定レイヤーに 2 つのキーが増えました**: `T` = スクロールの効き方の切り替え、
  `O` = オートレイヤーの ON/OFF。
- トラックポイントの速度設定・オートレイヤー・音声フィードバックの操作は従来どおりです。

詳しい操作は[キーボード操作ガイド](../docs/OLSK60_user_guide.md)と
[マウス機能操作マニュアル](../docs/OLSK60_mouse_manual.md)をご覧ください。
