# OLSK60 ファームウェア

> **このページはファームウェア v3.0.0 以降の案内です。**
> 旧版（v2.x）の案内は [v2.0.3 時点の説明](https://github.com/techmech-keeb/OLSK60_v2/tree/v2.0.3)をご覧ください。
> ファームウェアは[最新リリース](https://github.com/techmech-keeb/OLSK60_v2/releases/latest)からダウンロードできます。

このフォルダには OLSK60 キーボードのファームウェアに関する案内が含まれています。
本書ではファームウェアの選び方と書き込み手順を扱います。

> 設定ツールの概要・使い方は、[キーボード操作ガイドの「キーマップのカスタマイズ」](../docs/OLSK60_user_guide.md#キーマップのカスタマイズ)に集約しています。

## どのファイルを書き込むか

**ファームウェアの機能はどちらも同じです。**配布ファイルが 2 つあるのは、
**出荷時のキーマップ（プリセット）**が 2 通りあるためで、スペース列ごとに
「書き込んだらそのまま使える」配置を用意しています。

| お使いのスペース列 | そのまま使えるプリセット |
|---|---|
| **5 分割**（v2.1 の出荷時） | `OLSK60_v2_firmware_v<バージョン>_Vial_5split.uf2` |
| **3 分割** | `OLSK60_v2_firmware_v<バージョン>_Vial_3split.uf2` |

**どちらを書き込んでも動作します。**キー配置は Vial でいつでも変更できるので、
あとから好みに合わせて割り当て直すこともできます。

> **プリセットが合っていないとどうなるか:** 例えば 3 分割のキーボードに 5 分割用の
> プリセットを書き込むと、Space が物理キーの無い位置に載るため、そのままでは Space が
> 打てません。**Vial で押せる位置に割り当て直せば、そのまま使えます。** 手間を省きたい
>場合は、最初からお使いのスペース列に合うプリセットを選んでください。
>
> 設定ツール側のレイアウト選択は画面表示の切り替えで、打鍵の割り当ては変わりません。
> 書き込んだ直後の Vial の Layout タブは **3-Split Space** 表示です。5 分割のキーボードでは
> 「5-Split Space」を選び直してください（表示だけの設定で、選び直しは保存されます）。

### 設定ツール

v3 は **Vial 専用**です。**Remap / VIA には対応していません。**
キーボード定義はファームウェアに内蔵されているので、定義ファイルの読み込みは不要です。

## 書き込み手順

1. キーボードを PC から取り外します。
2. **ESC キーを押しながら** USB ケーブルを接続します。
3. `RPI-RP2` という名前のドライブが表示されます。
4. ダウンロードした `.uf2` ファイルを、そのドライブにコピーします。
5. コピーが終わるとキーボードが自動的に再起動します。
6. Vial で認識されることを確認してください。

> ファームウェアが起動しない状態でも、**ESC キーを押しながら挿せば**この書き込みモードに入れます。

## 書き込む前に

- **書き込むと、キーボードに保存された設定（キー配置・マクロ・トラックポイントの速度など）は
  初期化され、出荷時の状態に戻ります。** v3.0.0-rc.4 以降どうしの書き込みであれば、書き込む前に Vial の
  `Save Current Layout` で保存し、書き込み後に `Load Saved Layout` で読み込み直せます。
- ⚠️ **旧版（v2.x）と、v3.0.0-rc.3 以前のテスト版で保存したレイアウトファイル（`.vil`）は読み込まないでください。**
  独自キー（速度設定・サウンド・オートレイヤーなど）の並びが変わっているため、読み込むと
  **別の機能が割り当てられます**。Vial は保存元のキーボードを確認しないので、そのまま書き込まれます。
  これらから移行する場合は、お手数ですが Vial で組み直してください。
- 書き込み中は USB ケーブルを抜かないでください。
- v3 をお使いで問題がない場合、v3 の新しい版への更新は必須ではありません。

## 元に戻すには

旧版（v2.0.3）に戻す場合は、[v2.0.3 のリリース](https://github.com/techmech-keeb/OLSK60_v2/releases/tag/v2.0.3)から `.uf2` をダウンロードし、
上と同じ手順で書き込めば戻ります（このときも設定は初期化されます）。旧版の使い方は
[v2.0.3 時点の説明](https://github.com/techmech-keeb/OLSK60_v2/tree/v2.0.3)をご覧ください。

## v3 の主な変更点

旧版（v2.x）からの主な違いです。

- **設定ツールは Vial のみ**になりました（Remap / VIA 非対応）。
- **スペース列ごとに出荷時キーマップ（プリセット）を用意しました**（上記）。機能の違いはありません。
- **同時に押せるキーは 6 キーまで**です。
- **レイヤーが 5 つになりました。** 自由に使える予備のレイヤー（レイヤー3・初期状態は空き）を追加し、
  マウスレイヤーは一番上のレイヤー4になりました。
- **左親指のキーが Scrl キーになりました。** 押している間は Fn レイヤーがそのまま使え、押しながら
  トラックポイントを動かすとスクロールになります。
- **トラックポイントのスクロールが滑らかになりました。** 1 ノッチより細かい単位で送るため、
  ゆっくり動かしたときの追従が改善します。強く操作するほど速く進む調整も既定で有効です
  （設定レイヤーの `T` で切り替えられます）。
- **設定キー（Delete の右）**: 押している間が設定レイヤー（レイヤー2）です。**短くタップしてから押し続ける**と
  予備のレイヤー（レイヤー3）に入ります。
- **設定レイヤーを作り直しました。** 速度・加速・減速・オートレイヤーの時間は、Q / W / E / V で対象を選び、
  ↑ / ↓ で調整します。配置と操作は[キーボード操作ガイド](../docs/OLSK60_user_guide.md#レイヤー2設定レイヤー)を
  ご覧ください。
- **LED の色を整理しました。** 緑 = オン・完了、赤 = オフ・受け付けない、黄 = 上限です。
- **出荷時の設定に戻すキー**（設定レイヤーで 5 を 2 秒押し続ける。キー配置は変わりません）を追加しました。
- **トラックポイントの押し込みクリックをオン / オフ**できるようにしました（設定レイヤーの `G`）。
- **調整枠（速度4・速度5）の基本速度の上限を引き上げました。** トラックポイントの反応が弱いと感じる場合は、
  速度5 を選んで基本速度を上げてお使いください。

詳しい操作は[キーボード操作ガイド](../docs/OLSK60_user_guide.md)と
[マウス機能操作マニュアル](../docs/OLSK60_mouse_manual.md)をご覧ください。
